# Shweta Clinic — Landing Page

Landing page for Shweta Clinic, a family medical clinic and laboratory on
Munnekollal Main Road, Marathahalli, Bengaluru.

Plain HTML/CSS/JS, no build step — `index.html` is the entry point.

## Local preview

```
python3 -m http.server 8000
```

Then open http://localhost:8000
